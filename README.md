## What it is

Personal portfolio and resume site for Nathaniel Nikolai Ladero, Backend Developer. It presents experience, skills, projects, and contact as a terminal-themed single-page app. The live site deploys to GitHub Pages from the main branch.

## Build from source

Prerequisites: Node.js >= 20.11 and pnpm 10.33.2.

```powershell
git clone https://github.com/nathwn12/nathwn12.github.io.git
cd nathwn12.github.io
pnpm install --frozen-lockfile
pnpm run dev
pnpm run check
pnpm run build
```
